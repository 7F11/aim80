When I developed Z80 programs in the 80s the most useful tool was the Microsoft M80 macro-assembler.
I have never seen such a feature rich assembler.
However I could run it under CP/M emulator only. Now I provide a native C version.

It was created by AI support (therefore I had to migrate from Codeberg) with manual optimization. 
It is tested thoroughly and it is bit-by-bit compatible with the original.
It can produce the original (bit oriented) REL files as well as a new object format called REX, also designed with AI support.
Linker and library manager is also created, handling both object format.
